## 2024-06-14 - Mobile Navigation Toggle Accessibility Pattern
**Learning:** Found a recurring pattern in both standard and admin mobile navigation (`MobileNav.tsx`, `AdminMobileNav.tsx`) where icon-only toggle buttons lacked required `aria-label`, `aria-expanded`, and `aria-controls` attributes, and inner decorative icons were exposed to screen readers. Keyboard users also lacked focus indicators on these primary navigation interactive elements.
**Action:** Always ensure that any custom-built hamburger menus or icon-only interactive toggles dynamically bind `aria-expanded` to state, correctly link `aria-controls` to the container `id`, explicitly hide the nested Lucide icons with `aria-hidden="true"`, and provide `focus-visible` styles using the `brand-accent` token for consistent application-wide keyboard accessibility.
