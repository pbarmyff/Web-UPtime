## 2026-05-13 - Dynamic Accessibility Attributes for React Components\n**Learning:** Standard static HTML ARIA attributes are good, but React components toggling visibility (like mobile nav menus) need dynamic ARIA attributes linked to component state (e.g., `aria-expanded={isOpen}`) for proper screen reader communication, along with focus ring visibility classes to satisfy WCAG keyboard navigation requirements.\n**Action:** Always map the visibility boolean states of toggles to `aria-expanded` and explicitly link the toggle to its corresponding container using `aria-controls` with an explicit `id`.
