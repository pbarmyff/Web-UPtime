## 2024-06-10 - Mobile Navigation ARIA Pattern
**Learning:** Mobile menu toggle buttons that control overlays need specific dynamic ARIA attributes (`aria-expanded`, `aria-label`, `aria-controls` linked to an explicit `id`) and focus rings to be accessible to screen reader and keyboard users.
**Action:** When creating or modifying interactive UI components like sidebars, dialogs, or mobile nav toggles, implement proper dynamic ARIA state and ensure focusability.
