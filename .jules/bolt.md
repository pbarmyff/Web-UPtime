## 2024-05-24 - Async Interval Pile-ups with Sequential Processing
**Learning:** In a globally scoped `setInterval` execution environment (like Next.js `instrumentation.ts`), sequentially `await`ing multiple asynchronous I/O operations (like HTTP requests in a monitor loop) can cause the execution duration to exceed the interval frequency. This results in interval "pile-ups", memory leaks, and severe performance degradation across the entire system.
**Action:** When implementing repeating array processing inside background intervals, always batch concurrent executions (e.g., using a chunked `Promise.allSettled` approach) instead of a simple sequential `for...of` loop to ensure processing completes before the next interval tick. Explicitly process the returned results array to catch and log rejected promises to prevent silently swallowed errors.
