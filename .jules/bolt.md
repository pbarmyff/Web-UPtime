## 2024-05-26 - Dispatch network operations concurrently in loops
**Learning:** In notification loops involving external HTTP requests (e.g., triggering alerts/webhooks), awaiting each request sequentially inside a `for...of` loop leads to O(N) wait times. A single slow downstream service can block notifications to subsequent, unrelated services, causing arbitrary delays in alert delivery.
**Action:** When triggering multiple independent network operations (like webhooks or emails) from a list, always use `Promise.all` with `Array.prototype.map` to dispatch them concurrently, reducing total execution time to O(1) (the duration of the slowest request). Ensure each operation is wrapped in a dedicated `try/catch` block so failures are isolated and don't halt the entire `Promise.all` execution.
